# 真实使用小规模试点方案

状态：**方案已准备，未邀请参与者、未启动试点。** 用户选择沿用本机或已有SSH访问，不开放公网。入口说明见 [LOCAL_ACCESS_V7.md](LOCAL_ACCESS_V7.md)。本轮完成的是可审查的方案，不代表已经获得真实用户或新的算法证据。

## 目标、人群与时间

仅验证已有内容网站能否承接真实阅读、持续保留同一浏览器历史并形成兼容成熟反馈。暂定3–5名已有本机/SSH权限、愿意自主阅读技术新闻的使用者，不为凑人数创建账户、共享服务器凭据或扩招。没有自动发送邀请。

开始前记录明确的北京时间T0，连续观察7天，到期结束，不按反馈多少延长。7天应能在2026-11-22 08:00北京时间前结束，为既有观察器11月23日08:10收尾留出24h成熟时间；若无法满足则另行规划，不挤占或延长v4窗口。当前没有T0或实际参与人数，不预填完成状态。

这是自愿试用人群，存在选择偏差。日志中1–5或10次行为表示窗口内记录数，不代表用户生命周期阅读量或新注册身份。3–5人也远小于既有每阶段、每主组200人的先导下限；本试点不会被宣布为“通过冷启动研究准入”。

## 开始前的实际操作

| 步骤 | 执行者 | 完成证据 |
|---|---|---|
| 选择本机或已有SSH方式 | 项目负责人及已有权限的使用者 | 使用说明中的地址能从实际客户端打开 |
| 排查浏览器技术问题 | 技术检查者，仅在8768隔离服务和独立浏览器配置 | test_events=true；成功/失败原因记录 |

| 日常观察与到期结案 | 项目负责人使用原只读审计 | 汇总可用性、反馈、成熟情况和缺失原因 |

参与者说明可直接使用：

> 这是现有技术资讯网站的小规模使用观察。请只在确有兴趣时阅读或收藏，不需要点击指定文章、每天打卡或达到任何次数。网站使用匿名浏览器标识记录曝光、点击和收藏，供反馈可行性审计；目前没有已验证的新推荐收益。可以随时停止使用。请不要提供SSH密码或Cookie。

自然使用在固定浏览器配置进行，技术检查使用另外的配置。禁止在生产端执行“点击5篇再点到10篇”等任务；技术测试只进入隔离库，不复制到真实库。现有服务端决定is_test，不能由客户端切换；也不通过事后修改生产事件标记掩盖测试。

## 人群标记与证据边界

试点登记在本机私有文件中维护，字段至少为：试点编号、加入时间、T0/结束时间、访问方式、首次feed请求ID及其用途（自然使用/技术检查）、退出时间。登记在查看点击或推荐表现前完成；首次请求ID可由使用者在Network中查看feed响应提供，不收集Cookie或认证头。没有请求ID时保留“无法关联”，不按点击结果猜测身份。

如需关联，由只读查询请求ID取得匿名用户标识并在私有目录保存对应关系；不收集真实姓名作为研究键，不提交原始身份到Git。首次打开前后的其他浏览器身份无法可靠合并，明确记录局限。

v4观察器和哈希分桶完全不变，可能会统计试点产生的合法非测试事件。因此审计汇总必须注明试点来源，不把观察器总数当作未经选择的自然流量。所有已用于试点诊断或方法设计的用户/日期，在未来效果协议中按已使用数据处理；不得继续充当独立最终留出。试点登记缺失或跨设备关联不清的数据不能冒充独立人群。

## 观察指标与结束条件

每天沿用北京时间08:10的原观察器，查看最新已完成输出；不新增轮询服务，不重跑效应检验。只汇总实际出现的数据：

- 实际客户端访问成功与失败原因；诊断请求与自然feed分开。
- 新feed请求、兼容快照、可见曝光、点击、收藏及对应UTC日期。
- 固定24h窗口内的成熟情况，分开报告原始行为数、去重文章数和有效历史数。
- 缺快照、身份变化、测试污染、事件未确认等异常；零点击本身不是采集故障。

7天后只作下列可行性判断，不计算算法提升：

| 情况 | 结论与动作 |
|---|---|
| 实际客户端打不开、或出现可复现链路错误 | 记录具体环节；只有定位到的访问/采集缺陷进入后续修复，不扩大算法范围 |
| 入口正常，但没有自然feed或成熟反馈 | 结案为真实使用/反馈不足；不延长、不造样本、不继续调参 |
| 有自然使用与成熟兼容反馈 | 说明链路具备初步可用性；仍不等于研究样本量、独立性或推荐收益达标 |

若出现需要处理的误记录或故障，暂停试点说明中的使用安排并保留证据；不自动删除生产行为、改数据库、停站或回滚模型。当前方案不包含任何自动线上操作。

## 固定的研究与部署决定

v6同步记录优化已停止，原型仍关闭；不为本试点引入第三种存储方案。网站只保留原策略和回退，不重训，不启用新兴趣策略或生成配额实验。即使有人使用，也没有完整生产全目录重放合同，`full_catalog_replay_supported=false`、`efficacy_authorized=false`继续成立。
