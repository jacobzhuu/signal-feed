# 低成本自然冷启动兴趣表示：第三轮预注册

基线 `3426a00`，旧轮报告不改写。旧 adaptation-v1/v2 数据、预测、决策与验收文件的 SHA256 保存在新运行 `frozen_previous.json`；保留失败运行。实验不修改线上策略、不推远程。

## 独立数据与时段

仅复用经过内容身份核验的 large 目录、向量、原始日志与 small 排除表。不复用旧轮选择/准入/测试用户：保守排除 adaptation-v1 与 v2 的全部六份样本（即使未实际评分），再排除全部已匹配 small 的 94,065 large 用户。身份与排除输入均绑定哈希。

从 large dev 中选每位剩余用户最早的合格请求，必须原始历史长度属于 1/2/3/4/5/10，全部历史和曝光在冻结目录中；不截断成熟历史伪造自然少行为。保留原始行为数与去重证据数，重复行为不增加可信度。不读取标签选择用户。用户 SHA256(`interest-v3/split/`+user) mod10：0–2 select、3–5 guard、6–9 test。按日志日内 00–12 / 12–24 两个固定时段分层（日志时区未知，沿用旧解析），每个历史数×时段按 SHA256(`interest-v3/sample/`+user) 排序，select/guard/test 分别最多100/200/400人；不足不补样、不改样本量。每用户仅一条请求，三个集合互斥。列出日期、时段、train已见与未见、每个行为长度与去重长度、可达目标。此为同历史时期独立用户验证，不是未来日期或真实注册时间验证。

## 有界候选与计算

冻结文本编码器，不训练大模型，无生成/CF残差参与新方法。内容基线为原 ColdFuse 无先验内容向量（去重后最近线性加权中心），零信号回退热门。

新方法维护最多3个原型，最近相似原型余弦≥0.65时更新，否则在有空位时创建，满员时更新最近原型。每个独立行为使各原型累加量衰减0.85，再给分配原型加入向量、质量1。原型方向归一化，独立支持量为原型质量减去其最大单条行为质量；可信度 r=support/(support+tau)。这不将主题分散等同于证据不足，单例原型不能放大偶然点击。全局线性加权中心由向量和与位置加权和维护。评分 `(1-alpha)*global + alpha*max_j(r_j*prototype_j + (1-r_j)*global)`。一次目录矩阵乘法同时计算中心和最多3个原型。新独立行为 O(Kd) 更新；重复/窗口过期时按最后20条去重历史重建 O(20Kd)，保证与批处理一致。不缓存用户目录分数，不声称每次更新会减少重新检索成本。

仅四个候选：alpha∈{0.25,0.5} × tau∈{1,3}，固定K、阈值和衰减。不因结果扩大搜索。选择目标为 select 自然1–5全部用户等权 Recall50；同分优先alpha更小、tau更大。10次与时段不参与选参。

对照：content_safe、旧轮纯兴趣表示（multi=1,recent=.25，无侧路）、新纯兴趣、no_multi（只用全局中心）、no_reliability（r=1）、no_recency（仅原型衰减改为1）、popularity、修正ItemCF。消融只改一个模块；batch/incremental为语义等价工程核验，不作为不同质量方法。所有候选上限100，同样可用性、历史过滤和Recall分母。报告Recall20/50、端到端NDCG5/10、曝光AUC/MRR/NDCG。生成器不加载。

## 准入、最终检验与停止

配置在select后封存。guard独立用户上两项主要比较：新方法减内容，分别自然1–5总体、自然10总体。用户bootstrap10,000次95%区间、双侧符号翻转10,000次，Holm2校正；每组≥200人、区间下界>0、校正p≤.05，且两个时段各≥100人且均值差≥0、总体端到端NDCG10差≥0才获准。每个总体是固定组，不按单个长度开放新组。

test仅运行一次，同样两项主要检验、同样稳定性条件，独立判断是否复制准入证据；其余基线/消融/长度/时段差值及区间均探索性。确定性表示只运行一次，不能把重复种子或重复请求当作样本。guard拒绝则guarded直接复用内容；最终结果不反向修改准入。

只有至少一个总体同时通过guard和test，才允许启动另外预注册、另取未用用户的固定生成配额实验（总候选仍100）；否则本轮停止生成融合研究，不扩大参数或降低统计门槛。即使通过MIND验证也不自动发布HN。

## 成本与工程

每种方法在test每个长度×时段固定哈希前20用户独立调用，无结果缓存、轮转顺序，先各预热一次；记录p50/p95、预测一致性、单线程BLAS、硬件、驻留目录字节、进程峰值RSS、初始化时间。单独测量历史重建与追加更新（固定长度1/3/5/10，完整逐事件轨迹核验），不将其当作端到端HTTP成本。内容、新方法、旧纯兴趣使用相同目录和top100实现。归档全部负结果与原始预测。

全部Python、Ruff、前端构建、Playwright回归；浏览器只连接test_events=true隔离服务。真实8765仅健康检查，保持原进程、模型及内容回退。
