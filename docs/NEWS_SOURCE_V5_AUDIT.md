# 两份外部新闻数据的准入审查

2026-10-29；协议与实现冻结于 `c1d6296`。本轮只审查 EB-NeRD 和 Adressa，**均未准入为自然冷启动收益的独立最终证据**。没有进行新的效果比较、训练或参数选择。官方材料、HTTP 元信息、文件哈希和有限样本核查保存在 `artifacts/replay-v5/source-audit/`。

| 来源 | 官方覆盖与字段 | 当前目标的主要缺口 | 本轮决定 |
|---|---|---|---|
| EB-NeRD | 2023-04-27 至 06-08；行为分片各7天，附此前21天固定历史；train/validation 有展示与点击列表 | 用户根据后续05-18至06-08的5–1000次点击筛选；少历史不等于未经未来活动筛选的自然新用户；官方test缺点击标签 | 不下载行为数据；可作为另行限定人群的辅助时序基准，不能直接回答原问题 |
| Adressa | 官方提供一周及约三个月轻量事件档；主要是访问页面事件 | 缺明确展示未点击列表；窗口之前历史不可见、缺注册时间；历史文章版本不完整 | 仅核查2MiB压缩前缀，不下载全量、不构造效果样本 |

EB-NeRD 的人群筛选、日期、固定历史与标签说明来自[官方数据描述](https://recsys.eb.dk/dataset/)。固定历史必须随分片内事件按请求时间更新，后续研究还须屏蔽未来汇总统计并审查文章更新时点。数据为丹麦语，和现有以英语为主的编码器及 HN 领域不同，直接复用会混入语言与领域变化。数据访问要求登记姓名、邮箱、单位并接受研究用途条款；本轮没有提交资料或接受条款下载行为数据。[官方使用条款](https://recsys.eb.dk/assets/pdf/general_license_terms.pdf)

Adressa 的[官方主页](https://reclab.idi.ntnu.no/dataset/)与[字段说明](https://reclab.idi.ntnu.no/dataset/cxdataset_v5.pdf)提供访问事件、时间、匿名用户和部分文章字段；完整正文另行申请。公开轻量数据按[CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/)提供，不能把公开可下载理解为可直接商用。主页与说明的规模口径存在差异，本轮不把宣传数量当作全量核验结果。

实测下载官方 `one_week.tar.gz` 的前2,097,152字节，服务器返回206，压缩包总字节数为1,414,905,649。解压硬上限16MiB，最多读取第一个普通成员的500条完整JSON行；未解包到磁盘，也未访问全量行为。

| 有限前缀核查 | 实测 |
|---|---:|
| 完整事件行 | 500 |
| 含标题行 | 228 |
| 与旧实验目录规范化标题完全相同的行 | 0 |
| 显式展示列表字段 | 未观察到 |
| 按事件时间换算的UTC日期 | 全部为2017-01-04 |

第一个成员名为 `one_week/20170105`；文件名和UTC日期不同，因此不能用档名代替事件时区转换。该前缀不是随机样本，不支持估计自然1–5/10次用户规模、跨日比例或完整语料重叠。没有标题匹配也不能证明独立；匿名ID跨发行版不能直接关联，更不能证明自然人完全不重叠。

这些限制不表示数据完全无研究价值。Adressa可以在另立目标后研究“观测窗口内少历史用户的下一次访问”，但没有展示日志时不能把未访问项当作已展示负例，也不能称为策略反事实收益。EB-NeRD可以研究经过活动筛选人群的时序泛化。两者都需要新的问题定义、语言适配审查和独立协议；本轮不扩大范围来启动实验。

复现审查时必须使用新目录；网络文件可能变化，结果以本次保留的来源哈希为准：

```bash
.venv/bin/python scripts/audit_news_sources.py \
  --output artifacts/replay-v5/source-audit-NEW \
  --previous artifacts/adaptation-v2
```

机器可读结果见 [replay_v5_evidence.json](replay_v5_evidence.json) 中的 `source_audit`。没有新增数据准入，也没有使用旧测试集重新选方法。
