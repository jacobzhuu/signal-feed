## 保留的限制与潜在风险

这些限制没有被包装成“已消除”。它们不构成测试标签泄漏的已确认事实。

- **P1 风险：跨域质量及真实反馈不足。** MIND→HN 权重只在可辨识的实验入口使用；没有成熟真实点击时不晋升、不声称 CTR 收益。进一步结论需要独立成熟真实数据或受控在线实验。
- **P2 风险：目录与兴趣代理。** `first_seen` 是日志首次出现而非发布时间；原始历史最多 20 条，代理兴趣来自更早的有限历史。主 Recall 保留所有目标，同时报告可达率；模拟成熟用户截断与自然冷用户单列，不能称为真实 onboarding 效果。
- **P2 风险：容量。** 单实例 SQLite、同步持久化、单个有界生成工作进程仍可能有尾延迟与 busy 回退。压测分别报告实际模型/缓存/回退，稳定画像有利于缓存，不代表高基数、持续变更画像的容量。扩容需独立测量数据库方案和有界工作池，不用 HTTP 成功率代替生成完成率。
- **P2 风险：统计能力。** 验证主样本 300、测试主样本 1,000；三种子不能当作独立用户。区间按用户聚类，消融为固定权重的推理干预；多重比较区间未校正。小差异、跨零区间和负面结果均保留。

## 架构结论

ColdFuse 已作为独立核心接入原网站与独立成熟反馈训练路径。候选、先验收缩、门控与语义特征在线上/离线共享；HN 目录与协同信号由适配器提供。原发现、搜索、收藏、旧研究路由和旧线上模型契约保留。扩展入口已经具备，但以上数据、跨域及容量限制仍应作为后续迭代的验收条件。

工程验证、实验提交/哈希、所有方法/预算的指标和成本见 [RESULTS.md](RESULTS.md)。
