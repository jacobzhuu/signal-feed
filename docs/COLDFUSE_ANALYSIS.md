# ColdFuse 首轮结果解读

本轮工程与复现实验完成，**没有证据支持 ColdFuse 在本协议下稳定优于内容基线**。ColdFuse 保留为可辨识的实验入口；默认发现流仍使用原有内容策略。完整数字、全部消融和区间见 [RESULTS.md](RESULTS.md) / [cold_results.json](cold_results.json)。

## 已验证的结论

1. **全目录召回未改善。** 无显式兴趣、5 次阅读时 ColdFuse Recall50 为 0.005033，内容为 0.009667。无显式兴趣的 3/10 次预算，以及代理兴趣的 1/5 次预算，ColdFuse－内容的用户聚类区间完全低于 0；这些区间未校正多重比较。其他多个预算同样是负均值，不能以个别相对原 DNN 的正差值宣称整体提升。
2. **生成候选的潜力未转化为融合收益。** 单路 SID 前缀在代理兴趣 3 次预算达到 0.016567，而 ColdFuse 为 0.004333。无显式兴趣五个预算的完整－去生成 Recall50 均为 0；代理兴趣 1 次为 -0.000333、10 次为 +0.000667，其区间都包含 0。这里的“0”是本批目标命中的差值，不代表生成代码未运行或候选列表完全相同。
3. **显式代理并不保证冷启动收益。** 0 次阅读时，代理兴趣 ColdFuse 为 0.001167，去先验为 0.002533。代理来自最多 20 条日志历史中更早的类别，不能当作真实用户自己选定的兴趣；类别原型过粗是可能解释，不是已证明的原因。
4. **自然冷人群同样没有收益证据。** 51 个自然空历史请求中 ColdFuse 与热门/原 DNN 的 Recall50 都为 0.019608；249 个自然 1–5 历史请求中 ColdFuse 为 0.002008，热门和内容均为 0.006024。它们与成熟用户截断模拟分开统计。
5. **线上闭环可运行，线上质量仍未知。** 真实目录、兴趣更新、点击/收藏、快照、独立成熟反馈训练及模型发布/加载已验证。用实际特征的合成回归能够完成晋升和加载，但真实库没有成熟反馈，因此真实训练返回数据不足，不发布模型、不宣称 CTR 收益。

## AUC 需要怎样解读

ColdFuse 在 impression 评测时对全部给定曝光候选计算 DNN；没有进入召回池的条目，其**融合底分**为 0，最终混合分仍可能非 0。全目录路径则只在融合后的至多 100 个候选内精排。因此“曝光候选可区分”不能证明“能在全目录找到这些候选”。

例如代理兴趣 0 次预算，ColdFuse AUC=0.615537，原 DNN=0.575254，但 ColdFuse 全目录 Recall50=0.001167。原 DNN 保留旧特征契约，没有显式兴趣特征；同样的先验只进入它的候选通道，不能把这一 AUC 差值解释为同等信息下的纯融合收益。内容基线接收相同先验，其 AUC、端到端指标也完整保存在 JSON/CSV。

AUC 按 impression 宏平均，单类请求跳过；MRR 使用 MIND 多正例平均倒数排名。impression 同分保留原候选顺序，全目录同分按 ID 稳定排序。所有正目标保留主 Recall 分母；主样本的请求等权可达率从预算 0 的 0.99875 变为预算 3–10 的 0.99775，已读过滤的影响没有通过删除目标隐藏。

## 可供下一轮预注册验证的解释

内部验证中无兴趣 0 次预算的热门 Recall50 为 0.041222，测试仅为 0.002533。验证阶段选择了 generation=0.25 的较弱生成通道，当前融合可能过度依赖在验证期较强的热门先验。这与测试表现一致，但尚不是因果归因。

后续可在新的未使用时间留出上，预先规定多个验证时间窗口、通道权重尺度/候选配额和先验质量对照，再检验上述解释。本轮不根据测试结果重选参数，不新增有利子集，也不把当前测试重新称为全新 holdout。

## 成本的实际含义

最终 HTTP 负载含 16 个会话、8 种画像，每个客户端分别访问推荐和搜索，并写入请求快照与测试曝光。最后一轮三个并发级别的个性化请求均由模型或缓存完成，但稳定画像有利于缓存；此前过期/忙时回退及修复前锁竞争数据也保留。并发 32 请求 p95 约 2.78s，曝光写入 p95 约 3.31s，仍不能当作生产容量。

服务父进程与生成子进程在一次暖态观测中 RSS 约 1.05GiB / 0.54GiB（包含运行时与编码器等，不只是 156,673 参数的 DNN）；记录位于 `artifacts/coldfuse-v2/reports/runtime_resources.json`。真实跨域首次模型加载仍会触发约 2 秒的内容回退，生成工作有 30 秒硬期限。空历史且无兴趣已直接返回同一热门结果，避免无效模型等待。
