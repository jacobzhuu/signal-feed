## 工程验证与成本

- Python **40 passed**，Playwright **9 passed**，TypeScript/Vite 与 Ruff 通过；记录在 `artifacts/audit-v2/reports/validation.json`。
- 每个种子重评全部 **73,152** 个 impressions 的排序及同一 **1,000** 个请求的召回；排序指标与原权重记录精确一致，召回/端到端 NDCG 从逐条预测复算误差为零。
- 编码器、码本、SID/DNN 权重复用经过审计的原产物，**未声称重训**；重新以分块方式构建 ItemCF，内部验证 **2,000** 请求选择 threshold=10、generated weight=1.0。
- 隔离 HN 服务使用真实目录，16 个测试客户端覆盖无兴趣、显式兴趣、5 次点击历史，混合搜索、推荐、压缩快照和测试曝光写入。各并发级别 160 请求，均无请求错误。

快照 248 份，压缩后平均 **90.4 KiB/请求**，范围 53.3–129.5 KiB。编码为无损 float32 二进制加 zlib，并非重建历史特征。

新的性能负载包含反馈写入、多用户和不同历史，不能与旧 80 次无反馈负载直接比较。并发 32 的高尾延迟揭示同步持久化和共享主机下的容量限制，**不宣称性能全面提升或生产容量**。当前仍为 SQLite 单实例；成本数据和限制均保留。

研究推理实际返回：2.290s 超时回退、0.041s busy 回退、0.050s 模型缓存结果。两秒为等待预算，不包括准备和 HTTP 开销；任务另有 30 秒硬期限。只证明真实权重推理与回退可用，不证明跨域质量。

成熟真实反馈仍为 0，在线训练返回 `insufficient_real_feedback`，没有真实模型晋升或 CTR 收益。

## 可验证结论与下一阶段

1. 全量 MIND 排序结果仍可复现；受控去生成消融已消除其他通道权重变化。
2. 三种子完整模型 Recall@50=0.013375±0.001247，去生成=0.009560±0.000503。seed 42 用户聚类差值区间跨零，不能声称稳定显著增益。
3. seed 42 空历史和 1–5 历史的完整模型－去生成差值均为 0；样本分别只有 24 和 149。现有生成融合没有提供可验证的冷用户增益，这正是下一阶段要独立验证的问题。
4. ColdFuse 尚未实现。预注册的算法、0/1/3/5/10 配对模拟、代理兴趣限制、对照/消融和成本协议见 [COLDFUSE_DESIGN.md](COLDFUSE_DESIGN.md)。结果无论正负都保留。
