## 方法与独立实现贡献

新方法为 `stream-interest-v3`，纯兴趣表示，不含生成、CF残差、热门混合或DNN重排。内容基线是现有无先验、去重最近线性加权中心；全部方法同目录、同过滤、最多100候选、Recall@50口径一致。

- 多兴趣：最多3个原型，余弦0.65为固定分配阈值；满员后更新最近原型。避免每次对全部历史逐条做全目录相似度。
- 少行为可信度：每个原型的支持量为衰减行为质量之和减去其中最大单条质量，可信度为support/(support+tau)。单次点击不制造重复支持；这是证据收缩启发式，不是校准的点击概率。
- 增量更新：向量和、位置加权和精确维护原内容中心；原型累加量衰减0.85。普通追加只计算O(Kd)；重复或20篇窗口过期时重建有界历史，保证与批处理一致。更新画像不等于重新获取推荐，无目录分数缓存。
- 目录评分：一次矩阵乘法同时算中心及最多3个原型，再把原型分数按可信度收缩到内容分数。没有改变编码器或码本。

贡献是为本项目独立实现并验证上述组合及工程合同，不声称提出全新的聚类、收缩或在线统计理论。单例可信度、有限原型、精确增量一致性和一次目录投影均有可运行实现及回归；质量是否改善只由独立实验证据决定。

## 为什么停止

唯一参数集合为alpha∈{0.25,0.5}、tau∈{1,3}，共4组。自然1–5选择用户上四组Recall50均为0.009500；按预设同分规则选择alpha=0.25、tau=3。没有依据单个长度、晚时段或消融重新选择参数。

独立准入自然1–5共2,000人、自然10共400人，所选方法相对内容逐用户Recall50差值全部为零，Holm p均为1，两组拒绝。即使候选列表发生变化，也不能把检索列表变化称为收益。零差值的bootstrap区间[0,0]只反映本次稀疏指标无观察变化，不是总体等效或不劣证明。

准入和最终均采用两项用户级双侧符号翻转检验与Holm校正，并要求95%区间下界>0、两时段均值非负、端到端NDCG10不下降。最终结果不反向开放准入组。所有基线、单模块消融、行为长度及时段差值完整报告，探索性区间不替代主要检验。确定性方法运行一次，不把不同随机种子的统计抽样当作独立训练复现。

由于不存在同时获得独立准入及最终复制支持的组，本轮不开始生成式配额研究；不借候选互补性绕过纯兴趣前置条件。线上继续现有 `content-v1`，原ColdFuse实验入口及内容回退机制不变。现有 `GuardedAdapter` 的版本/域检查也未放宽；本轮MIND决策文件不能作为HN发布授权。

## 最终结果与消融解释

最终自然1–5共3,952人，内容与新方法Recall50均为0.008730，逐用户差值全部为零，Holm p=1；其中1,902人的top100列表改变，命中用户仍为相同41人。自然10共800人，内容0.006429、新方法0.007054，差值+0.000625、95%区间[0,+0.001875]、Holm p=1。其正差值仅来自1人，无法证明稳定收益；另一人的前十排序损失使总体NDCG10从0.001337降至0.000960。早时段Recall差为0，晚时段+0.001250，不能称为稳定时段提升。

去多兴趣与内容一致。自然1–5去可信度Recall50为0.009708，较内容均值+0.000978，但探索性95%区间[-0.000034,+0.002159]、原始p=0.100690；早时段为正、晚时段为负。旧纯兴趣Recall50为0.009666，差值区间[-0.000843,+0.002724]，原始p=0.323568，且NDCG10仅0.000609，低于内容0.001242。去原型衰减在自然10保持同样Recall50，NDCG10为0.001558；这些均不能据最终测试重新选法，也未证明衰减或可信度模块有独立质量收益。

这种结果与“保守收缩抑制了部分兴趣变化”的假设相容，但不能据此宣布去可信度有效。全体4,752人中112人有重复历史、1,315人在large训练日志未见；6,139个正目标仅3个不可达，全部保留分母。最终没有新增目录文章的正目标，因此不声称物品冷启动收益。稀疏命中和单日数据是重要限制，完整分群与负结果均保留。
