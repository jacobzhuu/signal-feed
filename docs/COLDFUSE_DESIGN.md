# ColdFuse 设计与实验预注册

状态：共享核心、网站与实验执行器已实现，实测结果待运行。参数只从内部验证集选择，不依据测试结果增删方法。

## 真实场景与贡献范围

场景是首次访问技术资讯站的匿名用户：可先选择明确兴趣，再在 1–5 次阅读后改变推荐。HN 的内容、显式兴趣和反馈来自真实应用；MIND 只用于历史日志实验。保留原发现、搜索、收藏与内容回退，并提供可辨识的 ColdFuse 实验入口。

本项目的独立贡献是把**兴趣先验的逐步收缩、观测可靠度、协同支持度、SID beam 集中度和冷阶段精排强度**组合成共享的离线/线上模块及受控实验。不是宣称首次提出混合推荐、语义 ID 或不确定性感知推荐，也不宣称复现 Qwen/GRPO。

参考边界：

- [TIGER / Recommender Systems with Generative Retrieval](https://arxiv.org/abs/2305.05065)：语义 ID 自回归召回已有研究基础。
- [MiniOneRec 官方仓库](https://github.com/AkaliKong/MiniOneRec)：复用现有项目固定的 SID 训练/约束解码路线；不更改上游副本。
- [Uncertainty-aware Generative Recommendation](https://hexiangnan.github.io/papers/kdd26-UGR.pdf)：生成不确定性已有相关工作；这里使用的 beam 集中度仅是启发式代理，不是校准概率，也没有实现论文的 RL 方法。

## 算法接口

输入仅包括请求前可见目录、固定文本向量、最近 k 条历史、可选显式兴趣、训练期 ItemCF/热门统计，以及冻结 SID 模型。输出候选 ID、分数、来源贡献、门控权重、可靠度、实际历史数、回退原因和模型版本。

1. **兴趣快速适应**：以显式兴趣向量作为先验，历史按最近程度加权；历史证据强度由独立条目数与语义一致性共同决定，使用 `n/(n+tau)` 连续收缩。无历史时使用先验；没有先验时不制造个人内容信号。
2. **动态召回融合**：热门/新鲜度兜底、内容语义、正支持 ItemCF、SID 前缀展开。内容权重随可用兴趣证据提高；ItemCF 权重依赖历史与协同支持；生成权重依赖可用语义证据和 beam 集中度。没有支持的通道必须为空。候选融合预算统一为 100，同分确定性处理。
3. **显式兴趣与生成**：允许把请求前可用目录中与显式兴趣接近的文章作为明确标记的语义锚点，辅助 SID prompt；它们不算真实点击，不写用户历史或反馈。生成只负责候选，不创造真实点击标签。
4. **精排**：在训练集上进行 k∈{0,1,3,5,10} 的历史遮罩增强，使用固定文本、候选注意力、显式兴趣、历史长度/可靠度等特征训练 DNN。禁止把全训练累计 ItemCF/热度重新用于训练行特征。根据证据强度混合融合分数与 DNN 排序，避免冷用户被通用 DNN 淹没。
5. **服务**：共享同一用户状态与融合函数；生成放在有硬期限的独立工作进程中，缓存绑定目录和模型版本。故障保持完整内容策略。跨域 MIND 权重仅在实验入口使用并明确标识；真实在线模型必须经过版本校验和独立成熟反馈验证。

## 严格实验协议

- 继续采用已审计时间切分；编码器和码本冻结；SID 与原 DNN 复用经过校验的基线权重，ColdFuse DNN 独立训练。记录全部来源与参数。
- 固定 0/1/3/5/10 次历史预算。同一请求在所有预算、模型、种子上配对，禁止把不同用户样本混成预算收益。
- 主要模拟从有足够请求前历史的用户抽取固定样本，截取最近 k 条。另报告自然空历史/少历史用户，避免把成熟用户的人工截断称为真实新用户实验。
- **无显式兴趣**为独立场景；**代理显式兴趣**作为辅助场景。MIND 没有真实 onboarding 标签，代理只能从不参与最近 10 条交互预算的更早历史中提取类别偏好，类别向量只用训练边界前内容拟合。不能从当前/未来曝光、点击目标或测试总体标签构造偏好。所有对照获得相同代理信息，报告它是模拟侧信息，不能声称等价真实显式兴趣。
- 每个 k 的所有方法共享请求、目录可用性、已知已读过滤和正目标分母。所有正目标保留主 Recall 分母；同时报告可达率、可达 Recall 和实际观测数。测试集不选择参数。
- 内部验证选择有限、预先声明的 tau/生成强度/精排混合参数；保留全部 trials，测试结果好坏都报告。
- Baseline 至少包括热门、内容（含相同显式兴趣）、ItemCF、SID/前缀、固定融合、修复后的自适应融合及原 DNN。消融至少包括去显式兴趣、去生成、固定门控、去兴趣收缩、去 DNN；其他参数与预算保持不变。
- 指标：impression AUC/MRR/NDCG@5/10；全目录 Recall@20/50、端到端 NDCG、候选覆盖、可达率；按预算/场景/自然冷人群报告分母；用户聚类配对区间，不把模型种子当独立用户。
- 成本：离线训练时间/样本数、各阶段与整条链路延迟、冷/热缓存、模型参数、实际候选数、超时回退；真实目录 HTTP 测试与合成回归严格区分。不要求超过基线。

## 验收与代码审阅重点

新增单测应证明：无历史无先验不会产生伪个性化；一次真实交互可以改变状态；改变测试标签不改变特征/候选；显式代理与观测预算不重叠；受控消融不修改其他权重；线上与离线同输入同输出；模型/目录变化使缓存失效；无模型/空目录/超时可回退；反馈快照为实际使用的请求前输入。

浏览器应证明：选择兴趣、首次推荐、连续阅读、再次推荐、搜索与收藏、反馈写入及隔离标记正常。最后逐项核对目标、报告、原始预测、运行命令、模型契约和实际服务，证据不足不标完成。

## 预先固定的首轮实验规模与选择规则

- 使用 seeds 42/43/44；主要模拟每个种子固定抽取 1,000 个有至少 15 条请求前历史的 impressions，两个兴趣场景及全部五个历史预算共享 ID。自然冷人群另外报告，不混入模拟均值。
- 代理兴趣来自 `history[:-10]` 中频次最高的至多两个类别；观测预算只来自 `history[-10:]` 的最近 k 条，两者严格不重叠。类别原型向量只根据训练边界前可用新闻文本平均计算，无点击标签权重。主结论同时报告完全没有代理兴趣的场景。
- 首轮验证固定抽取 300 个满足相同条件的内部验证 impressions；每个预算均有 300 条，而不是从总体样本中事后筛出很少的冷用户。训练检查点仍只用内部验证损失。该规模用于明确的原型实验，不能暗示已充分统计检验微小增益。
- 参数候选：`tau ∈ {1,3,5}`，生成通道强度 `g ∈ {0.25,0.75,1.25}`，DNN 最大混合强度 `a ∈ {0,0.25,0.5}`。优先按验证阶段 0/1/3/5 的场景/预算等权均值选择，保存所有 27 个候选及各分组得分；10 次交互用于暖化外推检查。若实现需要调整计算方式，必须在第一次 ColdFuse 测试运行之前记录原因。
- 默认每路最多 100 候选，融合最多 100，展示/评测 top K 不变。生成最多 20 beams，每个语义前缀最多展开 5 个条目；各方法实际候选数单独报告。不同预算同一方法推理成本也分别报告。
- 不根据测试结果再次调参或删掉失败消融。若发现实现错误，保留失败记录、修复原因及重跑说明，不能把错误修复后的测试称作从未使用过的新 holdout。

## 实现细节补充（首次 ColdFuse 测试运行前固定）

- 首轮 DNN 统一抽样 30,000 个训练 impressions、3 epoch、CPU 训练，避免争用当前其他 GPU 作业。每行用种子独立均匀选择一个预算和一个兴趣场景；不复制成十倍训练数据。训练采用 tau=3；验证阶段可在固定权重上评估预注册 tau 网格。2,000 个内部验证 impressions 的固定遮罩用于检查点损失，不使用测试标签。
- 六个额外语义特征为候选与状态/最近条目/先验相似度、独立历史数、可靠度、收缩系数。DNN sigmoid 仅用于把排名分数限制到融合分数的尺度，不是校准 CTR。
- 代理兴趣先从最多 20 条原始预处理历史中取 `[:-10]`，再去除与最后十条重复的条目，防止同一文章同时成为先验与观测证据。无可用旧类别时先验为空。
- 所有方法接收相同代理兴趣内容通道；原始 DNN 保留原特征契约，不能直接接收新增先验特征，其候选仍含相同先验。稀疏检索方法在 impression 排序中未召回候选统一记为 0；这些 AUC/NDCG 与语义 DNN 的候选内区分能力需分别解读。
- 单独抽取 300 个自然历史 0–5 请求，按空历史/1–5 分层，不与人工截断样本混合。完整三种子差值先在相同 impression 内平均，再按用户 bootstrap；区间为探索性、未校正多重比较。
- 生成进程持久复用权重，最多一个待处理任务，2 秒请求等待、30 秒硬期限、128 个请求缓存。目录、先验、历史、CF、热门与全部模型契约/权重绑定缓存；过载或模型不可用返回共享核心的内容/CF/热门结果。
- ColdFuse 在线反馈独立使用 `cold-semantic-v1` 和 `cold-online-models`，继承原成熟窗口、时间剔除、用户聚类晋升及验证消费规则；不污染原 `online-text-v2` 模型。无真实成熟反馈时只报告数据不足。
