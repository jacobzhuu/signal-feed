# ColdFuse 与少样本兴趣适应：第二轮解读

状态：参数选择、独立准入和工程回归已完成，最终留出评估与成本测量尚在运行。本页不能用来宣称最终测试收益；完成后更新完整数字和结论。

## 这轮实际改变了什么

稳定基线 `b747819` 已通过标签 `stable-coldfuse-b747819` 保留。现有前端和真实服务策略没有改变，没有新增大型模型，没有推送远程。实验核心冻结在 `26bd564`，报告工具在主工作区独立维护，核心文件哈希必须一致。

旧结果说明主要瓶颈在候选融合，而非单纯缺少更强DNN。无先验、5次行为时，旧热门/内容/生成平均门控约0.802/0.661/0.0249；只有约8.6%的生成候选进入融合100候选。四路联合池中的大量正目标在DNN之前已丢失。历史平均向量的范数又把语义分散和证据不足混在一起，历史增加没有持续提高内容权重。完整证据及图见 [瓶颈诊断](ADAPTATION_DIAGNOSIS.md)。

本轮实现一个轻量的兴趣适应方法：保留逐条历史的最大相似度，单独控制最近行为，按历史与先验的一致性抑制冲突先验；有个人信号时以内容为主，CF/SID只作保守残差重排。选择验证从预先固定18组参数中选出 `multi=1, recent=0.25, side=0.5`。没有重新训练编码器、SID或DNN；这不是一个新大型模型。

这种保守融合有已知边界：当内容池充足时，权重≤0.5的单侧独有候选无法仅靠自身分数进入top50。因此它可以检验表示和重叠候选重排，但没有完整解决生成候选的独立配额分配。SID单路、原等权固定融合、固定侧路以及去侧路/去生成都保留，不能以该方法代替对互补性的完整分析。

## 为什么这次留出与旧测试不同

旧MIND-small测试已使用过，本轮不把它重新称作新留出。MIND-large中排除所有能够对应旧small事件的用户，然后按固定用户哈希分出选择、准入、最终评估三个互斥集合。主模拟分别600/600/1200人，自然少历史各600人；同一用户仅取最早合格请求，模拟与自然样本也互斥。

实际核查发现small/large的数字ID不属于同一命名空间：原始同名ID中，36,131篇只有1篇标题/摘要相同。最初`adaptation-v1`因此在选择完成前停止，保留部分预测与failure.json，不使用其指标。修正版`adaptation-v2`以完整内容对应全部65,238篇旧新闻，以不含标签的事件指纹匹配全部230,116个旧唯一事件，保守排除94,065个large用户。原small内部的train/dev身份一致，第一轮基线不受这个跨版本问题影响。

最终目录88,053篇，新增22,815篇沿用原编码器和冻结码本，CF/热门仍仅使用旧训练统计。可用性采用请求之前的首次日志出现；所有正目标保留Recall分母。目录和人群已改变，不能把第二轮数字直接减去第一轮数字当作提升。

## 三种“冷启动”必须分开

- **截断模拟**：同一批成熟用户截取0/1/3/5/10次行为；代理显式兴趣来自不重叠的更早历史。这不是真实新注册用户，也不是在线连续反馈曲线。
- **自然少历史**：日志实际只有0–5条历史；每个长度点是不同用户。最终600人中165人在large训练日志未出现，全部为dev首次请求；这只能称作首次观测用户，无法推断注册时间或在其他窗口是否活跃。
- **真实HN用户**：本轮只读检查没有真实行为事件，无法估计CTR或新用户收益。离线MIND证据不授权HN模型发布，服务保持原稳定策略。

用户留出仍来自同一历史时期、共享新闻目录，不能证明未来时间段或跨域稳定性。用户bootstrap衡量该时期的用户差异，不覆盖新的新闻事件/日期带来的全部不确定性。

## 独立准入实际拒绝了什么

参数选择后，三个种子在另一批600模拟和600自然用户上验证。按“有/无先验×独立历史0/1/2–5/6+”八组判断，要求用户数≥100、配对Recall50差值95%区间下界>0、八项Holm校正p≤0.05。

八组均未通过。代理先验2–5组平均差值+0.004742，95%区间[-0.002064,+0.011985]；无先验2–5组+0.003290，区间[-0.001118,+0.007937]。6+组均值为负。正均值不等于稳定收益，因此全部选择`content_safe`。

运行时`GuardedAdapter`先判断该组是否获准，再决定是否调用侧路；被拒绝时连生成调用都不会发生。该对象执行域和策略版本检查，MIND准入不能被直接当成HN准入。测试中的回退结果必须与内容基线完全相同；这种相同来自没有启用新方法，不能包装为新方法本身稳定。

## 最终解读规则

最终完整报告将保留所有15个方法、全部预算、自然分层、三种子、关键消融、候选互补、早/晚时间切片与成本。九项主要用户配对检验进行Holm校正；预算与分群区间为探索性。曝光AUC与全目录Recall的候选支持不同，不能把AUC差值解释为端到端召回收益。

同一用户先平均种子及预先规定的预算，再做bootstrap和符号翻转。确定性内容/兴趣表示的重复种子不是独立训练证据。成本使用预编码目录、驻留权重/索引、无结果缓存、轮转方法顺序的独立调用，不包含HTTP、数据库写入或文本编码；真实HN在线容量仍需另行测量。
