# ColdFuse 第二轮：兴趣快速适应分析

最终独立测试与成本复核尚在执行；本页先记录已经封存的诊断与准入决定，不能作为最终效果报告。

## 已确认的瓶颈

旧样本的逐请求诊断见 [诊断报告](ADAPTATION_DIAGNOSIS.md)。主题一致性与证据量混用，使多主题历史受到惩罚；热门权重长期较高，低权重生成候选在进入 DNN 之前被截断。无显式兴趣、5 条历史时，内容 Recall50 为 .009667，ColdFuse 为 .005033；三路各100候选的联合覆盖为 .03479，但这个更大的池只用于诊断，不是同预算推荐结果。

曝光 BCE 训练与实际检索候选分布不一致、sigmoid 和 RRF 尺度未校准，是代码支持的设计限制；当前实验不能分别确认它们造成了多少损失。曝光 AUC、全目录 Recall50 和端到端 NDCG 必须分开解释。完整训练与模型保持冻结，本轮没有通过扩大模型解决这些问题。

## 轻量适应与独立准入

`interest-adaptation-v1` 保留逐条历史最大相似度，混合最近行为，并以先验和观测历史的一致性抑制冲突先验。有个人信号时以内容为主，无信号时用热门；CF/SID 仅作残差融合。18组配置只在独立选择集选择，结果为 `multi=1, recent=0.25, side=0.5`。

该融合有一个提前披露的边界：单一侧路独有候选最高分 .5/61 小于内容第50名的 1/110。它主要检验表示与重叠候选的重排，尚未解决独立互补候选的预算分配。去多兴趣、去可靠度、去侧路、去生成及固定侧路权重全部保留，不在最终测试后扩大参数网格。

独立准入集的八个预定义人群均未通过“至少100用户、配对区间下界大于0、Holm校正p不超过.05”的门槛；全部 Holm p 为1。因此 **guarded 对所有人群返回 content_safe**。部分组均值为正不足以启用，最终测试也不能追溯改变这项决定。回退在调用生成器之前生效，并校验策略版本与证据所属域。

## 数据可信度与适用边界

- 稳定基线为 `b747819`，本地标签 `stable-coldfuse-b747819`；正式算法冻结于 `26bd564`，标签 `adaptation-canonical-v2`。报告和成本工具的后续提交不代表重新训练或重新选参。
- 初次 `adaptation-v1` 错把 MIND-small/large 原始匿名ID当作共同命名空间，已在完成参数选择之前停止；没有准入或最终测试结果。失败记录与部分预测保留，不能用于结论。
- 修正版按文章内容精确关联原65,238篇文章；按无标签事件指纹完整匹配230,116个已暴露唯一事件，保守排除94,065个large用户。修正版88,053篇目录的原向量、码本、CF和热门保持绑定，新文章只使用相同冻结编码器与码本。
- 选择、准入、最终测试按规范化之后的large用户身份划分且互斥。最终为1,200模拟用户与600自然少历史用户；模拟预算0/1/3/5/10来自同一批成熟用户的历史截断，不是连续上线学习。
- 自然组原始日志历史为0–5条，其中165人未在large训练日志出现；“日志未见”没有注册时间证明。600人均为dev首次请求，各历史长度对应不同用户，不能把其横截面曲线解释为个人成长轨迹。
- 本轮是同一时期独立用户评估，并非未来时期留出。真实HN没有足够行为反馈，无法给出真实注册新用户CTR或线上质量收益。MIND准入文件不授权HN部署。
- 三个冻结模型种子先在同用户内平均；主要九项检验进行Holm校正。预算、时间、新旧目录与其他分群区间均属探索性，不据单个有利切片宣称稳定有效。
