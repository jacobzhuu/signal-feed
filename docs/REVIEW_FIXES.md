# SignalFeed Code Review 修复报告（2026-10-29）

本轮只修复五个已确认的问题，未开发 ColdFuse、未新增推荐模型、未改变整体架构。修复前基线为 `6552342`。实验输出隔离在 `artifacts/review-fix/`，没有覆盖原线上模型或把自动化流量混入真实反馈。

## 根因与修改

| 问题 | 触发条件与根因 | 修复及主要文件 |
|---|---|---|
| P1 训练泄漏 | 浏览器点击可在 1 秒曝光计时器之前到达；按曝光时间重建历史会把当前目标放进输入，且旧标签包含无限期之后的点击 | `serving.py` 保存推荐时历史、兴趣、特征与完整内容分数；`api.py`、`store.py` 原子保存请求快照；`online_learning.py` 只读快照、固定 24h 标签窗口、按请求时间切分并剔除标签跨界请求 |
| P2 晋升比较错误 | 旧基线仅是一个历史相似度特征，未代表完整内容策略或已经部署的 DNN | 读取当前已部署模型并在同一验证曝光上重新打分；没有在线模型时使用冻结的完整内容分数；记录 incumbent 版本和哈希、双方预测及时间边界，已有模型用过的数据不能再次用于晋升验证 |
| P2 收藏幂等错误 | 事件插入去重后仍无条件改变收藏；按 request/item/kind 唯一又阻止再次收藏 | 收藏仅对新事件产生副作用；收藏切换按事件 UUID 去重，曝光和点击保留原组合唯一约束；迁移在事务中完成，保留旧数据 |
| P2 前端请求竞态 | 旧请求的成功、异常及 finally 都能覆盖新页面 | `main.tsx` 对列表、错误、加载状态统一检查请求序号；重试保留当前地址；兴趣更新和旧卡片收藏回调不能覆盖之后的导航；收藏按钮提交时暂时禁用 |
| P2 安装绑定作者目录 | editable requirement 指向作者绝对 checkout | `requirements.lock.txt` 改成 `-e .`，沿用安装脚本先进入仓库根目录的行为；在不同路径实际安装并验证导入来源 |

## 重跑与对比

### 真实 HN 数据

修复前后都没有真实成熟曝光：0 次曝光、0 次正曝光，均返回 `insufficient_real_feedback`。因此未在真实库训练或发布模型，也没有可报告的 HN AUC、NDCG 或 CTR 提升。旧请求即使以后有点击也不会被回填成无泄漏样本。

### 延迟曝光对照（合成回归，不是线上收益）

150 个独立冷用户请求、300 次曝光、150 次提前点击，时间间隔一天。两版都训练现有 Ranker 5 epoch；训练 240 次曝光、验证 60 次曝光 / 30 个请求。正例在两个条目之间交替，推荐时没有可预测该选择的用户历史。旧版从基线源码加载，新版使用保存的请求快照。

| 指标 | 修复前 | 修复后 | 变化 |
|---|---:|---:|---:|
| 正例自身历史相似度 | 1.0000 | 0.0000 | -1.0000 |
| 候选 AUC | 1.0000 | 0.5000 | -0.5000 |
| 候选 MRR | 1.0000 | 0.7500 | -0.2500 |
| 候选 NDCG@5 / @10 | 1.0000 | 0.8155 | -0.1845 |
| 比较基线 AUC | 1.0000（泄漏的单特征） | 0.5000（完整内容策略） | 基线定义已纠正 |
| 晋升 | 否 | 否 | 均保留研究产物 |

下降是去除目标泄漏后的预期结果，不能解释为真实推荐质量恶化。新结果已重新训练和计算，没有沿用旧分数。已有在线模型的三种晋升场景由独立回归测试验证，不包装成真实用户实验。

### MIND 历史链路

重新审计训练 141,265、内部验证 15,700、留出 73,152 个 impressions，65,238 篇文章；无缺失元数据，时间满足 train < valid < test。

本轮重新训练 seed 42/43/44 的现有 DNN（各 3 epoch，每种子 1,011,937 个训练样本）和 seed 42 的无个性化消融。四组新权重与原权重逐张量完全一致。SID/编码器/码本/融合参数未改动，使用原冻结产物；不把它们描述为本轮重训。各种子重新评估全量 73,152 个留出 impressions 和同一固定抽样的 1,000 个全目录召回请求；全部重跑已完成：三种子排序、召回及互补性指标与修复前精确一致（Δ=0），均未沿用旧结果。DNN AUC=0.654458±0.001823，NDCG@10=0.403375±0.000734；完整融合 Recall@50=0.011226±0.000868。详细指标见 [RESULTS.md](RESULTS.md) 和 `review-fix-results.json`。

## 剩余风险及边界

- 没有真实成熟反馈，不能验证真实流量晋升效果；自动门槛不能替代 A/B 实验。
- 比较范围仅为已曝光候选上的排序；存在展示选择偏差，没有未展示条目的反事实标签。
- 缺少请求快照的旧样本必须舍弃；purge 和新验证窗口要求会进一步减少训练/验证样本。
- 快照增加 SQLite 存储和请求写入开销；本轮不引入存储压缩或自动清理。原始结果与性能测量都标注共享主机条件。
- 收藏重试须复用相同事件 UUID；不同 UUID 的请求视为新的用户操作。多个独立客户端并发新操作仍按服务端事务顺序生效。
- 在线训练和人工切换发布应串行运行；本轮能检测训练期间指针变化，但不提供跨进程发布协调服务。
- Python 测试存在依赖中的 Starlette/AnyIO 弃用提示，不影响用例通过。新机器仍需要项目现有 Python 3.11、Node 和相应依赖环境，并设置可写的 `SIGNALFEED_HOME`。
