# 数据可用性审查与内容全目录重放原型

基线 `cc144ad`。本轮只交付数据来源审查及隔离重放工程验证；不选推荐算法、不训练、不发布、不扩展旧参数搜索，现有网站与冻结v4观察器保持运行。

数据来源最多两个：EB-NeRD和Adressa。先读官方说明、字段与使用条件；最多下载Adressa官方压缩包前2MiB、解压上限16MiB、读取最多500条完整JSON，仅核对字段和身份。它是顺序前缀，不能估计完整人群规模。EB-NeRD涉及登记资料和事先条款接受，本轮不提交个人资料、不访问受条件约束的行为数据。保留HTTP信息、文档与样本SHA256、失败记录。官方说明中的日期/规模不冒充本机全量核验；匿名ID跨来源不可直接关联。

重放仅覆盖现有 `content-v1` 的非搜索、无在线DNN路径。新增参数必须显式传入记录器且环境为隔离测试；网站API不传入、默认关闭，不增加生产写入。被返回的历史文章仍按现有策略降权，不改为过滤；目录为服务该次实际使用的有效目录，不宣称涵盖整个HN。

目录按内容寻址版本保存文章ID/标题/发布时间/当时score/删除状态/更新时间、冻结384维float32向量及编码器合同；相同版本跨请求复用。记录器只接受只读向量，以服务目录对象身份和元数据检测刷新，避免每请求重新散列/复制全部向量；版本读取验证全部文件校验和。请求保存时间、目录引用与刷新时间、原始行为计数、全量去重历史及最后20条实际有效历史的精确次序、显式兴趣向量/文本、当时完整稀疏协同计数、完整分数校验和、实际返回序列及同策略top100。输入源与重放源码哈希绑定，不用未来数据库、当前目录或当前兴趣重新构造旧请求。

先测试目录新增/删除/改文、分数变化、未来点击/兴趣变化后重放不变；损坏、缺文件、预算/身份/版本不一致应拒绝。旧请求不补写；没有完整记录不能推断出候选。独立重放重算完整分数与top100，并与实际推荐结果比对。限于同数值环境的精确验证，跨硬件/依赖升级可能需要冻结环境重放，不能忽略分数校验失败。

成本在真实HN文章目录和冻结现有编码器上测量，但用户历史与反馈只在隔离数据库中构造，不能解释为推荐质量证据。使用0/1/3/5/10/25条历史各20个请求，轮转未记录推荐/记录推荐/重放顺序，全部无结果缓存。目录持久化与独立冷读取另外计时；记录p50/p95、每目录/每请求字节、目录复用和数值一致性。工程可接受目标仅为原型门槛：目录已登记时记录开销p95≤10ms、≤20条历史的每请求记录≤32KiB；任一不满足则只交付原型并保持关闭。这些门槛不是效果统计阈值，不能授权上线。

全量Python、前端构建、Ruff、隔离浏览器回归；生产服务不重启。通过原型验证也不自动升级采集合同或v4准入条件。若外部数据不满足自然冷用户、独立日期或标签要求，明确记录未准入，不为启动实验强行改定义。
